# Security policy

## Supported versions

ReSolver-RectangularGrids.jl is currently a development-only package and has no supported tagged release. Security fixes are applied to the default branch while the package is under active development.

| Version | Supported |
|:--|:--:|
| Default branch | Yes |
| Tagged releases | None published |

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's private vulnerability-reporting form for this repository:

<https://github.com/Davide-Lasagna-s-Lab/ReSolver-RectangularGrids.jl/security/advisories/new>

If private vulnerability reporting is temporarily unavailable, email Davide Lasagna at <davide.lasagna@soton.ac.uk>. Include the affected revision, a minimal reproduction when possible, the expected impact, and any suggested mitigation. You should receive an acknowledgement within seven days. We will coordinate disclosure after the issue has been assessed and a fix or mitigation is ready.
